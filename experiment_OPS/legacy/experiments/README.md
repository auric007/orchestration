# Orchestration experiment notes

This repository stores Markdown experiment plans and summaries for the
end-to-end project. It does not contain the research code, datasets, images,
model weights, checkpoints or raw outputs.

- Server notes directory: `/sfs/end_to_end/experiments/`.
- GitHub: `auric007/orchestration`, branch `main`.
- Laptop vault folder: `Obsidian Vault/Projects/orchestration/experiments/`.
- Plans: `next-plan.md` or another direct-child `.md` file.
- Results: append timestamped entries to `YYYY-MM-DD.md` (Asia/Kolkata).
- Maximum note size: 1 MiB. Only regular UTF-8 Markdown is synchronized.
- Saved drafts can sync approximately every minute. No agent or experiment is
  triggered by synchronization; ask the coding agent explicitly to run a plan.

Each experiment entry should state the goal, configuration and source version,
commands, aggregate metrics/tests, failures, conclusions and next steps.
The Git history here versions notes, not the server's ignored research code.
Never include credentials, private company material, samples or raw datasets.
Public access to these summaries was explicitly approved by the repository user.
